API Credentials (Support)

Customer taps Generate in Settings → API Keys to create a 10-character App Unique Key, then sends it to you. Enter that key here to generate App Key (20), Secret Token (25), and Client Token (10). Send those three tokens back — customer pastes them into Settings.
